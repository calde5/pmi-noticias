# Portfolio Monitoring Iberia · Noticias

Página informativa **no oficial** que recoge y resume noticias públicas de empresas de España y Portugal para el seguimiento de operaciones. No constituye asesoramiento.

- Web: https://calde5.github.io/pmi-noticias/portal/ (la raíz redirige aquí).
- Se actualiza automáticamente cada día hacia las 8:30 (hora peninsular).
- La página está en `portal/index.html`. Las noticias y los resúmenes van en el bloque JSON `news-data`. La contraseña es solo una pantalla de entrada y no cifra el contenido.
- `tools/datos.mjs` extrae, valida y guarda ese bloque.
