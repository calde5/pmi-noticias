# Portfolio Monitoring Iberia · Noticias

Página informativa **no oficial** que recoge y resume noticias públicas de empresas de España y Portugal para el seguimiento de operaciones. No contiene información interna ni confidencial y no constituye asesoramiento.

- Web: https://calde5.github.io/pmi-noticias/
- Se actualiza automáticamente cada día hacia las 8:30 (hora peninsular).
- Todo el contenido está en `index.html`; las noticias y resúmenes viven en el bloque JSON `news-data`.
